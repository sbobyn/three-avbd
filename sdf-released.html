Method & limitations

Four substeps, 20 AVBD iterations and five candidates per pair. Mesh quality activates contacts earlier and adds mesh vertex witnesses. Mesh fields retain the original resolution-100 bake. The CPU reference uses sequential impulses; trajectories differ. This is not a reproduction of the paper's GPU performance.
