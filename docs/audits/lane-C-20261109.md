## Label map contract (for the lead's gallery seam)

`src/comparison/labels.ts`, DOM-free and engine-free: its only import is `import type { CaseName }`, so the
gallery may import it.

- `CASE_INFO: Readonly<Record<CaseName, { label: string; bodies: number; summary: string }>>`: all 27 cases.
  `label` is the gallery chip wording exactly (checked by test). `bodies` is the dynamic body count, equal to
  `makeScene(name).bodies.filter(b => b.mass > 0).length` for every case (checked). `summary` is one sentence.
- `caseLabel(id: string): string` (an unknown ID comes back as typed), `caseSummary(id): string`,
  `FAMILY_LABELS: Record<string, string>` (`rest-grid-N`, `impact-N`, `pile-N`, `pile-N-settled`, `ring-N`), `familyLabel(familyId): string`.

`tests/comparison-labels.test.ts` already asserts that each chip label in the `side-by-side` catalog entry equals
`caseLabel(chip.covers[0])`, so a gallery label edit fails it until both agree.
