three-avbd examples

Small programs you can copy. Each links to its source in examples/; they use only the package's public entries (three-avbd, three-avbd/sdf, three-avbd/pool, three-avbd/queries). All need a WebGPU browser unless marked Node.

Basics

  • Basic world: a box pyramid, raining spheres, convex-hull rocks and a breakable joint chain. source
  • Static projectile Node, no GPU: CPU sphere sweeps against static meshes with three-avbd/queries. Run node --experimental-transform-types examples/static-projectile.ts. source

Bodies and lifecycle

  • Body lifecycle headless: enable/disable, reset, remove and slot reuse. source

Pools

  • Body pool headless: a fixed-storage World and a BodyPool recycling spheres. source

SDF collisions experimental

  • SDF gears: bake a gear mesh, mesh two gears, drive one kinematically. source
  • Balls in a torus: an analytic torus field keeps its hole, and holds the balls dropped into it. source
  • SDF from a mesh: worker bake, mass properties, principal frames, and the API's limits. source
  • Larger demos: SDF playground, gear train, released reference scenes.

Rapier-first paired study

Interlocking sculpture: two pre-linked rings, compound convex colliders, push/reset and observation export. Rapier baseline first; AVBD counterpart and matched measurements follow review.
