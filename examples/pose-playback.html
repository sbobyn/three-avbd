Pose playback

Plays back a pose track you captured yourself: body transforms read from a headless World by examples/pose-capture.ts (Node + Dawn, hardware GPU), drawn here with plain Three.js instanced meshes. Nothing is simulated in this page.

No track ships with the site. Run the capture command from the user guide, then choose the JSON file it wrote. The file stays in your browser; nothing is uploaded or stored.
