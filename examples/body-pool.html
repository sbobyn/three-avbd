Body pool (headless)

examples/body-pool.ts creates a World with fixed storage (storage: { growth: 'fixed', … }) on a device the page owns, then a BodyPool of 32 spheres from three-avbd/pool. Four rounds each acquire eight spheres, step twice and release them, so bodies are recycled instead of added and removed.

There is no rendering: the page prints what the function returns. Expect 32 different ids across the four rounds: the same pooled slots come back, but every acquire is a new lifetime with a new ID, so a stale handle can never be mistaken for its replacement. Then pool stats with leased: 0, and the fixed storage size in bytes. See Body pools.
